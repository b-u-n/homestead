## Overview

"Help Wanted" bounty board. A user posts a help request and stakes 1–9 hearts; the first responder wins the entire bounty. Cannot respond to your own posts. Real-time broadcasts to all connected clients; deep-link notifications for response events.

## Notes

Anchors [[spec/weeping-willow-posting]] and the central drop components (`WeepingWillowLanding`, `CreateWeepingWillowPost`, `PostsList`, `RespondToPost`). Full event tables, sort options, and example handler code live in `md/WEEPING_WILLOW.md` per R6.
