## Value

`rgba(0, 0, 0, 0.15)`

## Usage

Bottom and right border color on the inner emboss-border overlay View. Pairs with `token/color-emboss-border-highlight` to create the raised appearance — light top-left, shadow bottom-right.

## Notes

Inverting the pair (dark top-left, light bottom-right) produces an *inset* effect — see `md/EMBOSS.md` "Adjusting the Effect".
