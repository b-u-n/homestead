## Value

`rgba(92, 90, 88, 0.55)`

## Usage

The default color for every dashed stitched border in the app — `StitchedBorder` component output, `MinkyPanel` border, `Checkbox` indicator border (unchecked), `WoolButton` stitched border (unfocused). `md/ART_STYLE.md` rule: "always dashed, never solid".

## Notes

All four source docs agree verbatim. Universal value for the "stitched" line treatment.
