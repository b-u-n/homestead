## Value

`rgba(179, 230, 255, 0.25)`

## Usage

Overlay tint for `ButtonBase` variants `secondary` and `blue` (same value, two aliases). Also used by `MinkyPanel` in the "create post" area per `md/COLORS.md`. Light sky-blue accent.

## Notes

Single canonical value shared between button and panel surfaces. No drift.
