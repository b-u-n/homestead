## Value

`rgba(222, 134, 223, 0.25)`

## Usage

The default tint applied to a `MinkyPanel` and to `ButtonBase` variant `primary`. The defining "warm pink" of the Homestead aesthetic — most content surfaces wear this overlay by default.

Both source docs agree on this value verbatim. No drift.
