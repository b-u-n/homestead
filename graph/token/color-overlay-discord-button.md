## Value

`rgba(130, 140, 255, 0.35)`

## Usage

Overlay tint for `ButtonBase` variants `discord` and `blurple` (aliases). Used for Discord-themed external-link buttons.

## Notes

Only `md/COLORS.md` carries a value; `md/ART_STYLE.md` is silent. No drift.
